# Phone test checklist (about 20 minutes)

Do this once on a real **iPhone (Safari)** and once on a real **Android phone (Chrome)**. Use a test account, not a real client's. Write down anything that looks wrong and send me a screenshot.

The Toolkit tools only show "Ready" on a server where the owner has switched them on (staging does; production does not).

## 1. Open and install
1. Open the app's web address in the phone's browser.
2. Sign up with a test email and sign in.
3. Add it to the home screen (iPhone: Share, then Add to Home Screen. Android: menu, then Install app). Open it from the icon.
   - Check: it opens full screen, with the VIDHI icon and name.

## 2. Look and touch
4. Turn the phone sideways and back. Check: nothing is cut off and nothing scrolls sideways.
5. Open the Toolkit page. Check: every card can be read and tapped.
6. Tap into a text box (Toolkit, then "List of dates"). Check: **the page does not zoom in** when the keyboard opens (iPhone).
7. Tap the small links ("← Toolkit", "Add all to my calendar"). Check: you hit them first time.

## 3. Each tool (paste this into the text box, or upload any PDF)
Text to paste: `The accused is charged under Section 420 IPC. The hearing was on 5th April 2031. Pay Rs. ______ now. The the draft is not final.`

8. **List of dates:** run it. Check: the date shows, with "page not available" for pasted text. Press "Add to my Dates", check the date, press Add. Open Dates: the new date is there.
9. **Pre-filing defect check:** run it. Check: it points to the blank line and the doubled word, and says why each may not be a slip.
10. **Old-code to new-code checker:** run it. Check: it lists Section 420 of the Indian Penal Code and says "No verified mapping is recorded".
11. **Authority Check:** run it. Check: results appear and say what could not be checked.
12. **Deadline engine:** Check: it says "No reviewed rule is loaded yet, so nothing can be calculated". That is correct today.
13. On each report page, check the line "Kept until <date>, then deleted automatically", and try "Delete this check".

## 4. Files
14. Upload a real PDF from the phone (Files app). Check: it uploads and the report shows page numbers.
15. Download a Word or PDF copy of a report. Check: it opens on the phone.

## 5. Things that matter on a phone
16. Switch to Telugu or Hindi in Settings. Check: letters show properly, with no empty boxes.
17. Turn on airplane mode, then try a tool. Check: you see a clear message, not a blank screen.
18. Sign out and sign in again. Check: it works with no errors.

## Send me
- Phone model and browser version.
- For each step that looked wrong: the step number and a screenshot.
